# Community impact

Evidence-controlled inventory of **adoptions**, **contributor discoveries**, and
**independently verifiable outcomes** related to model-serving-minefield.

- Machine-readable: [`impact.json`](impact.json) (schema: [`impact.schema.json`](impact.schema.json))
- Generated prose: [`COMMUNITY_IMPACT.md`](COMMUNITY_IMPACT.md)
- Integrity: `python3 integrity/community_impact_integrity.py`

This is not a marketing counter. Unsupported success language is rejected by
the integrity checker. Narrow measurements need a wording guardrail.
