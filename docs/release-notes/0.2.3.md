# model-serving-minefield 0.2.3 (draft, not yet released)

These are the notes for the GitHub release and the PyPI description when 0.2.3
is tagged. Nothing here is published until the `v0.2.3` tag is pushed.

## Install or upgrade

```bash
pipx install model-serving-minefield        # or: pipx upgrade model-serving-minefield
```

`msmf` remains a short alias package that installs the same commands.

## What's new since 0.2.2

**Registry 166 → 175 traps.** 0.2.2 shipped 166 traps; `main` carried 168
after traps 167 and 168. This release adds seven more:

- **169**: a speculative-decoding speedup measured on plain greedy decode is
  not the speedup your workload gets (about +56% on the bench, 0% to 23% per
  output class on the same RTX 5090 lane).
- **170**: retrying capped thinking answers at double the token budget mostly
  buys a second loop; report loop rate and finished-item accuracy separately.
- **171**: unpaired confidence intervals hide a real sub-percent quality delta
  that a paired per-document comparison finds.
- **172**: tokens per second from agent wall time per call is not decode
  speed.
- **173**: a valid tool call is not proof of the correct tool choice.
- **174**: system-prompt drift can turn a literal command into a
  tool-discovery detour.
- **175**: restarting the model server without draining active agents drops
  the session's backing model.
- **167** and **168** (on `main` since 2026-11-08): a validated-pack gate with a
  family exemption, and a bulk `down --all` that stops only the first group.
- Trap **112** gains an addendum on endpoints whose owner was stopped by a
  watchdog.

**Easier to find your way in.**

- The README is now a short front door. The full symptom table is in
  `TRAPS.md` and the long-form guide in `docs/GUIDE.md`.
- New ExLlamaV3 / TabbyAPI stack page with three first checks.
- One install name everywhere.
- `CITATION.cff` and a code of conduct.

**Smaller changes since 0.2.2.**

- `minefield scan` notes when a detector count was capped (8 per rule, 256 per
  file) instead of showing a silent lower bound.
- The open-trap queue (`registry/OPEN_TRAP_ISSUES.md`) covers every open
  `[trap]` issue with CONFIRM and REFUTE criteria.
- A static site builder (`site/build_site.py`) and a manual Pages workflow:
  the offline search plus one page per trap.

## Unchanged

- Doctor coverage stays at 70 traps; 131 of 175 traps have at least one
  automatic check (`minefield coverage`).
- The MCP server's tools and the CLI's commands and flags are unchanged.

## Upgrade notes

- Anything that parsed the symptom table out of `README.md` should read
  `TRAPS.md`. The packaged registry (`dist/MINEFIELD_REGISTRY.json`) is
  unchanged in shape.
